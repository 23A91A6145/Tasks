# Example Support Queries

## Billing

| Query | Expected Classification | Tools Used |
|-------|----------------------|------------|
| I was charged twice for my subscription this month. Can you help? | billing | Currency, Data |
| Can you check invoice INV-1243 and tell me how much it is in EUR? | billing | Currency, Data |
| My invoice #1243 shows the wrong amount. Please fix it. | billing | Data |
| Do you offer student discounts on the basic plan? | billing | Data |
| I want a refund for last month's charge | billing | Data |
| Can you convert $99 USD to EUR for my international payment? | billing | Currency |
